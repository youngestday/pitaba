# ピタBA（旧名：Zengo）

左右に並べて、線を合わせて、ピタッで撮る。同じ構図のビフォーアフターカメラ。

左にビフォー写真、右にカメラのライブ映像を並べて撮影し、ビフォーアフター画像を1枚で保存するWebアプリです。

公開URL：https://youngestday.github.io/pitaba/

## できること

- ビフォーはその場で撮影、または写真ライブラリから選択
- シャッターでビフォーを撮った直後は、写真の下に「ビフォーを写真アプリにも保存［保存］［✕］」が10秒出る。［保存］で共有シートが開き、「画像を保存」で写真アプリに残せる（Web版では自動で写真アプリに保存できないため）
- 写真を選んでから表示されるまでは「写真を読み込んでいます…」と出る。続けて選んだときは順番に処理する。読み込めなかったときは、そのことを知らせる
- 撮らずに作る：最初の画面（ビフォー画面）のシャッターの左下「撮らずに作る」で（アフター画面では同じ場所が「ビフォーを撮り直す」になる）、空の完成画面を開く。左（ビフォー）・右（アフター）の写真をタップすると写真アプリが開き、選んだ写真が入る（撮った写真をあとから差し替えるのにも使える）
- 保存した写真：左上の「保存した写真」（どの画面からでも開ける）に、2つのタブで残る。ホーム画面に追加して使うと消えにくい
  - ビフォー：撮るたび（写真から選んだときも）保存（新しい30枚まで）。開くと、そのビフォーでアフターを撮れる。アフター画面では「今のビフォーを写真に保存」で写真アプリにも保存できる
  - ビフォーアフター：完成画面を作るたびに保存（新しい30件まで）。開くと完成画面に戻り、文字の書体・位置、比率などをあとから直せる（直すと同じものに上書き）
  - タップで選ぶ（もう一度タップで外す）。横になぞるとまとめて選べる（縦はスクロール）。1つ選ぶと「開く」、選ぶと「削除」が出る。ビフォーのタブでは「写真に保存」も出て、選んだ分（何枚でも）を共有シートから写真アプリに保存できる。削除は確認なしで、消したあと10秒間「元に戻す」で戻せる
- 右側のカメラ映像にビフォーの輪郭を線で重ねて構図を合わせられる（濃さを調整可能。線の色を「なし」にすると重ねない）
- レンズ切替：0.5x（超広角、対応端末のみ）／1x
- インカメ（前面カメラ）にも対応。鏡のように左右反転して表示・保存する。水平・垂直ガイドの「上に向ける／下に向ける」とスマホ形の枠は、背面カメラと同じくスマホの傾きで出す
- 一致度：次の2つの平均を出し、画面全体の似かたと低いほうを使う
  - ビフォーの「長くまっすぐな線」（壁と天井・床の境目、窓枠など動かないもの）のずれ
  - 場所ごとのずれ：画面を 上・中・下 × 左・右 の6つに分け、それぞれビフォーと何ピクセルずれているかを輪郭の向きの重なりから探す。いちばんずれている行（上・中・下）で点数を決めるので、上半分だけ合って手前（下のほう）がずれているときはピタッにならない。なくなった物はどうずらしても重ならないので判定に使わない。手前（下の行）は設定でOFFにできる
- 自動撮影：ビフォーとの構図の一致度（%）が設定した値を超えると、カウントダウン（時計回りに減る円のゲージ。0.3秒固定）のあとアフターを撮影。位置・画角合わせが主役なので、水平・垂直はよほど傾いていなければ（左右5度・前後7度まで）撮る
  （一致度は画面右上に表示。しきい値は50〜90%を5%刻みで調整）
- 構図合わせガイド（ガイドON/OFFで切替、アフター画面はOFFから始まる）：ビフォーに合わせるための動かし方を ↑↓←→ の矢印だけで表示（文字は出さない。線画を合わせることに集中できるように）。ずれが大きいほど矢印も大きい。「↓」は画面のいちばん下に出し、傾きのスマホ形の枠と重ならない
- ピタッ：一致度が設定値を超えると、緑の枠と「ピタッ！」の表示、音で知らせる。自動撮影ONなら、ピタッが出たら必ず撮る（ピタッと自動撮影は同じ条件。一度合ったら一致度が5%下がるまで合ったままにして、手ブレで数字が揺れてもカウントダウンが途切れないようにしている。アフター画面に入って1.5秒はピタッも出さない。ビフォーをまっすぐ撮っていて、アフターが大きく傾いているときもピタッは出ない）
- シャッター音（「カシャ」）
- 3×3のグリッド（アフターを撮るときは、左のビフォー写真にも同じグリッドを出して見比べられる。保存画像には入らない）と水平・垂直ガイド（左右の傾きで回る線は水平で黄色の1本に。まん中のスマホ形の枠は前後の傾きで台形になり、まっすぐ立つと黄色の長方形に）
- ビフォーの自動撮影：自動撮影ONのとき、水平・垂直がそろうとカウントダウン（設定で0.5〜2秒、初期値1秒）のあとビフォーを撮影
- 新しい版の確認：設定画面のいちばん上の大きなボタン「新しい版を確認」。結果はその場に出て、新しい版があればボタンが「新しい版に更新する」に変わる
- 保存した写真は、その端末の中だけ（インターネットには送らない）。ほかの人や、別の端末からは見えない
- 画面の並び：上の段は、左に「線の色」とその下に「ガイド」、右に「自動撮影」（0.5x・1x の上）。シャッターの左は上から「保存したビフォーアフター」「保存したビフォー」（押すとその一覧を直接開く）「写真から選ぶ」「撮らずに作る・撮り直す」の4段、右は0.5x・1x／比率・カメラ切り替えの2段（どれも同じ幅。横持ちでは左の上2つ・下2つが横2個ずつ並び、下は操作欄をスクロールして使う）。左上の「保存した写真」もそのまま残してある（完成画面などからも開けるように）。写真の欄は左上のボタンと重ならない。向きを変えたら操作欄を作り直す（iPhone で横→縦に戻したときに崩れないように）
- 設定画面（左上の「設定」）：ピタッの音・シャッター音・グリッド・手前（画面の下のほう）も合わせる・水平・垂直ガイドのON/OFF、ビフォーの自動撮影までの時間
- 撮影中はビフォーから壁・窓・家具の縁などの輪郭だけを取り出し、線にしてカメラ映像に重ねる（線の色は 赤／青／緑、「線なし」で重ねない。濃さも調整可）
- 重なりチェック：完成画面の写真のすぐ下のスライダーのつまみを左へ滑らせると、ビフォーが右へ・アフターが左へ寄って重なり、ずれを確かめられる（指を離すと戻る）。ビフォーは線画になって、アフター写真の上に重なる
- 1枚ごとの比率は 16:9／4:3／1:1 から選べる（どれも縦長。撮った後の完成画面でも変更可）
- 「BEFORE / AFTER」の文字を入れるか選べる。完成画面の「文字のデザイン」で、書体と位置を選べる（選ぶとすぐ完成画像に反映）
  - 書体（5種類）：標準（太いゴシックの丸い札。ビフォーは黒地に白文字、アフターはその白黒反転。どちらも少し透ける）／明朝（白い明朝体に細い下線）／クラシック（Didot の斜体に白いカード）／モダン（字間の広い細めの文字に四角い札）／ポップ（「はちまるポップ」の細い手書き風の文字の楕円のステッカー。傾けない。ビフォーは青、アフターはオレンジ。文字は BEFORE・AFTER）
  - 位置（8か所）：左上・中央上・右上・左下・中央下・右下・枠の外・上・枠の外・下（枠の外は、写真の上か下に白い帯を足してそこに入れる。標準だけは、札が白地と同化しないよう帯を薄いグレーにする）
  - 背景の色（12個を2段で。色の名前は出さず、色の丸だけ）：おまかせ（クラシックは茶色、明朝はベージュ、標準の枠の外は薄いグレー、ほかは白）／白／薄グレー／濃グレー／黒／ベージュ／茶色（コルクボードくらい）／焦茶色／パステルブルー／パステルグリーン／パステルピンク／パステルパープル。2枚の写真のすき間と、写真の四周の縁（すき間と同じ太さ）と、枠の外の帯の色になる。濃い色（濃グレー・黒・焦茶色）のときは、文字や札を明るくして読めるようにする。作品に保存され、開くと戻る
  - 書体は iPhone に入っているもの（ヒラギノ明朝、Didot、Avenir Next など）を使うので、電波がなくても保存画像に入る。ポップだけは「はちまるポップ」（Google Fonts、SIL Open Font License。英大文字だけを切り出して index.html に埋め込み済み）を使う
- 「保存・共有」から写真アプリに保存

## 使い方

1. iPhoneのSafariかChromeで上のURLを開き、カメラの使用を「許可」する
2. 左側でビフォーを撮る（または「ビフォーを写真から選ぶ」）
3. 右側のカメラで、重なったビフォーに合わせてアフターを撮る
4. 完成画面で「文字を入れる」を選び、「保存・共有」で保存する

ホーム画面に追加すると、アプリのように起動できます（アイコンは `icons/`、Android 用の設定は `manifest.webmanifest`）。
