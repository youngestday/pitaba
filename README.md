# ピタBA（旧名：Zengo）

左右に並べて、線を合わせて、ピタッで撮る。同じ構図のビフォーアフターカメラ。

左にビフォー写真、右にカメラのライブ映像を並べて撮影し、ビフォーアフター画像を1枚で保存するWebアプリです。

公開URL：https://youngestday.github.io/pitaba/

## できること

- ビフォーはその場で撮影、または写真ライブラリから選択
- ビフォーを撮ったあとの「写真アプリにも保存」の案内は出さない（保存は、下のタブ「ビフォー」で選んで「写真に保存」）。
- 写真を選んでから表示されるまでは「写真を読み込んでいます…」と出る。続けて選んだときは順番に処理する。読み込めなかったときは、そのことを知らせる
- 撮らずに作る：最初の画面（ビフォー画面）のシャッターの左下「撮らずに作る」で（アフター画面では同じ場所が「ビフォーを撮り直す」になる）、空の完成画面を開く。左（ビフォー）・右（アフター）の写真をタップすると写真アプリが開き、選んだ写真が入る（撮った写真をあとから差し替えるのにも使える）
- 一時保存：下のタブ「ビフォー」「ビフォーアフター」に残る。ホーム画面に追加して使うと消えにくい
  - ビフォー：撮るたび（写真から選んだときも）保存（新しい30枚まで）。選んで「アフターを撮る」を押すと、そのビフォーでアフターを撮れる（アフター画面で出していた「今のビフォーを写真に保存」は、一覧で選んで保存できるのでなくした）
  - ビフォーアフター：完成画面を作るたびに保存（新しい30件まで。完成した1枚も一緒に保存する）。開くと完成画面に戻り、文字の書体・位置、比率などをあとから直せる（直すと同じものに上書き）
  - タップで選ぶ（もう一度タップで外す）。長押し（0.45秒）で大きなプレビューを出す（ビフォーは保存した写真そのもの、BA は完成した1枚。前に作った BA は縮小版）。プレビューは2本指で広げると拡大（1〜6倍）、拡大中は1本指で動かせる。動かさずにタップすると閉じる。横になぞるとまとめて選べる（縦はスクロール）。1つ選ぶと「アフターを撮る」（ビフォー）／「修正する」（ビフォーアフター）が黄色で出る（2つ以上選ぶと灰色になって押せない。ほかのボタンがずれないよう、場所は残す）。選ぶと、写真に保存（ダウンロードのアイコンだけ）と削除（ゴミ箱のアイコンだけ）も出る。「写真に保存」は、選んだ分（何枚でも）を共有シートから写真アプリに保存する（BA は完成した1枚。2026.11.24-58 より前に作った BA は完成した1枚を持っていないので、保存を押したときに、保存した2枚と設定から作り直して BA に入れる。作り直したときは共有シートを出せないので「準備ができました。もう一度保存を押してください」と出し、2回目で保存する）。一覧を開いているときの知らせは、一覧の上（画面の上のほう）に出す。タブで開く画面（ビフォー・ビフォーアフター・動画・設定）は、ホーム画面から開いたときに時計・電池の表示の下にもぐらないよう、その分だけ上を空ける。削除は確認なしで、消したあと10秒間「元に戻す」で戻せる（10秒のあいだは一覧から隠すだけで、本当に消すのは10秒たってから。Safari で戻せなくなるのを防ぐため）
- 右側のカメラ映像にビフォーの輪郭を線で重ねて構図を合わせられる（濃さを調整可能。線の色を「なし」にすると重ねない）
- レンズ切替：0.5x（超広角、対応端末のみ）／1x
  - ライブ映像は、video をそのまま見せず、上にかぶせたキャンバスにアプリが枠いっぱいで描く（iPhone の Safari で、レンズを切り替えたあとなどに video が枠の中で小さく映り、まわりが灰色になる不具合があるため）。新しいコマが届いたらすぐ描く（requestVideoFrameCallback。使えないときは毎フレーム確かめる）
- インカメ（前面カメラ）にも対応。鏡のように左右反転して表示・保存する。水平・垂直ガイドの「上に向ける／下に向ける」とスマホ形の枠は、背面カメラと同じくスマホの傾きで出す
- 一致度：次の2つの平均を出し、画面全体の似かたと低いほうを使う
  - ビフォーの「長くまっすぐな線」（壁と天井・床の境目、窓枠など動かないもの）のずれ
  - 場所ごとのずれ：画面を 上・中・下 × 左・右 の6つに分け、それぞれビフォーと何ピクセルずれているかを輪郭の向きの重なりから探す。いちばんずれている行（上・中・下）で点数を決めるので、上半分だけ合って手前（下のほう）がずれているときはピタッにならない。なくなった物はどうずらしても重ならないので判定に使わない。手前（下の行）は設定でOFFにできる
- 自動撮影：ビフォーとの構図の一致度（%）が設定した値を超えると、カウントダウン（時計回りに減る円のゲージ。0.3秒固定）のあとアフターを撮影。位置・画角合わせが主役なので、傾きはビフォーとよほど違わなければ（左右5度・前後7度まで）撮る
  （一致度は画面右上に表示。しきい値は50〜95%を5%刻みで調整）
- 構図合わせガイド（ガイドON/OFFで切替、アフター画面はOFFから始まる）：一致度が設定値に届かないとき、何を直せばよいかを教える。ステップ0〜3に分けて、1つずつ出す。写真の外（縦持ちは下、横持ちは上）に、「ステップ ⓪①②③」の丸（合ったステップは緑の✓、いまのステップは黄色）と、いまやることを絵と文で出す。写真の中にも同じ絵を出す。
  - **順番は「0 傾き → 1 位置（左右・高さ）→ 2 前後 → 3 向き」**。位置（平行に動かしたぶん）は、近い所と遠い所のずれの差で測るので、向きがずれていても正しく測れる。逆に、向き（遠い所のずれ）は、位置を動かすと少し変わる。だから位置を先に決め、最後にその場で向きを合わせると、やり直しが出にくい。体の動きでも、足（立ち位置）→ 腕（高さ）→ 手首（向き）と、大きい動きから小さい動きの順になる。検証（ガイドに従う人を再現、奥行きのある場面、3通りの出発点）では、向きを先にすると遠くの景色のずれが平均1.2%残り、位置を先にすると0.6%だった
  - **「動かす」と「回す」を絵で分ける**：動かす（平行移動）は黄色で、点線のスマホ→実線のスマホ＋まっすぐな矢印。回す（その場で向きを変える）は水色で、台形に見えるスマホ＋曲がった矢印。前後は、小さい点線のスマホ→大きい実線のスマホ（近づく）とその逆（下がる）。文の頭にも「動かす」「回す」「傾ける」の札を付ける
  - **回転と平行移動の見分け方**：ビフォーの強い輪郭を、画面の上の4割（遠いことが多い）と下の4割（近いことが多い）に分けて、別々にずれを測る。遠い所はスマホを平行に動かしてもあまり動かないので、遠い所のずれ＝向き。近い物ほど大きく動く（視差）ので、近い所と遠い所のずれの差＝位置
  - ステップ0「傾きを合わせてください」：**ビフォーを撮ったときの傾きと同じにする**（水平・垂直とは限らない。ビフォーを傾けて撮っていたら、同じ傾きで線と枠が緑になる）。差が左右2度・前後3度以内で合格。ビフォーの傾きが分からないとき（写真から選んだとき）や、センサーが使えないときは飛ばす
  - ステップ1「位置を合わせてください」：「動かす 右へ／上へ（向きは変えず平行に）」。近い所と遠い所のずれの差が、幅の0.7%・高さの0.6%以内で合格
  - ステップ2「前後を合わせてください」：「動かす 前へ進んで近づく／後ろへ下がる」。大きさの差が1%以内で合格
  - ステップ3「向きを合わせてください」：「回す 右へ／上へ（その場で向きだけ変える）」。遠い所のずれが、幅の1%・高さの0.8%以内で合格
  - 上と下を別々に測れないとき（模様が足りない場面）は、全体のずれを「位置」として案内し（幅の1%・高さの0.8%以内）、向きのステップは飛ばす。平らな壁のように近い・遠いの差がない場面では、向きと位置は区別できないが、合えば同じ見え方になる。上が近く下が遠い場面（低い天井の照明など）では、位置の向きが逆に案内されることがある（ガイドは「下のほうが近い」と仮定）
  - 合格のあとは、合格の線の約2倍を超えるまで合ったままにして、行ったり来たりしない。前のステップが外れたら、そのステップに戻る。ずれが大きいほど絵も大きい。大きいほうの向きだけを出す（左右と上下を同時には出さない）
  - **基準は1つ（設定した一致度）**：「ピタッ」と自動撮影は、ガイドON でも OFF でも、一致度が設定値を超えたかどうかだけで決まる。超えていれば、ステップの途中でも「そろいました」にして、そのまま撮れる。ステップは、一致度がまだ足りないときに、何を直せば近づくかを教える役目。ステップが全部合っても一致度が足りないときは「ほぼ合いました」と出す
  - 位置の測り方：粗い推定（36×64・整数マス、画面の幅の約3%・高さの約1.6%刻み）を出発点に、4倍の細かさ（144×256）で「ビフォーの強い輪郭（上位12%）が、ライブ映像の同じ向きの輪郭に重なるか」を数え、小数点以下まで位置と大きさを求める（精度は0.05%ほど、1回約40ms）。物が変わった所は重ならないだけで、結果を狂わせない。重なりが弱すぎる（0.12未満）ときは、見失った扱いで絵を出さない
- ピタッ：一致度が設定値を超えると、緑の枠と「ピタッ！」の表示、音で知らせる。自動撮影ONなら、ピタッが出たら必ず撮る（ピタッと自動撮影は同じ条件。一度合ったら一致度が5%下がるまで合ったままにして、手ブレで数字が揺れてもカウントダウンが途切れないようにしている。アフター画面に入って1.5秒はピタッも出さない。アフターの傾きが、ビフォーを撮ったときの傾きと大きく違う（左右5度・前後7度を超える）ときもピタッは出ない）
- シャッター音（「カシャ」）
- 3×3のグリッド（アフターを撮るときは、左のビフォー写真にも同じグリッドを出して見比べられる。保存画像には入らない）と水平・垂直ガイド（左右の傾きで回る線は水平で緑の1本に。まん中のスマホ形の枠は前後の傾きで台形になり、まっすぐ立つと緑の長方形に。アフター画面では、ビフォーを撮ったときの傾きとの差を出すので、ビフォーを傾けて撮っていたら、同じ傾きで緑になる（「ビフォーと同じ傾き OK」）。ビフォーの傾きが分からないときは、本当の水平・垂直を出す）
- **ビフォーを続けて撮る**：ビフォー画面では、ガイドのボタンの場所（同じ位置・大きさ）が「連続撮影OFF／ON」になる。ONにすると、アフターの枠を消してビフォーのカメラだけを大きく映し（比率はそのまま）、撮ったあともビフォー画面にとどまり、撮るたびに「ビフォー」タブへ保存して「ビフォー ◯枚目を保存しました」と出す。アフターは「ビフォー」タブから選んで撮る。初期はOFF（1枚ずつの流れは今までどおり）。設定は覚える
- ビフォーの自動撮影：自動撮影ONのとき、水平（左右の傾き）がそろうとカウントダウン（設定で0.5〜2秒、初期値1秒）のあとビフォーを撮影
- 起動時のお知らせ（ベータ版）：立ち上げるたびに、アイコン・「ピタBA」・「ベータ版」・「使い勝手のフィードバックをお願いします」を出す。「フィードバックをする」（黄色で強調）で、一言書いて送れる（設定画面にも同じボタン。こちらも黄色で強調し、「閉じる」は枠線だけ）。「はじめる」は枠線だけ。その下の「次から表示しない」にチェックすると、次からは出さない（フィードバックは設定画面から送れる）
  - 送り先は Google フォーム（回答は作者のスプレッドシートにたまり、メール通知も受け取れる）。送るのは、書いた内容と、お名前（任意。書いたときだけ。次のためにこの端末にだけ覚える）、アプリの版・端末の種類・画面の大きさ・ホーム画面からかどうかだけ。写真は送らない。お名前は、フォームに専用の質問がないあいだは「アプリの情報」の先頭に「名前 ◯◯／」として入る
  - つなぎ方：`index.html` の `FEEDBACK = { form, text, info }` に、フォームの ID と、質問の番号（entry.◯◯）を入れてある（フォーム「ピタBA（β版）フィードバック」の「改善要望」と「アプリの情報」）。空にすると「フィードバックをする」ボタンを出さない
  - **写真を添える（スクショなど、3枚まで）**：`FEEDBACK.script` に Apps Script のウェブアプリの URL を入れてある（プロジェクト「ピタBA フィードバック受付」）。URL を入れると、「写真を添える」ボタンが出て、送り先が Apps Script に切り替わる（空のあいだは、これまでどおり Google フォームに送り、写真のボタンは出さない）。写真は送る前に、長い辺 1600 画素の JPEG に縮める（1枚 100KB 前後）。送ったあとは受け取り口の返事（{"ok":true}）を読み、うまくいかなかったとき（1日の上限など）は理由を出す。返事が読めない端末では、返事を見ずに送るだけにする
  - 受け取り口：`tools/pitaba-feedback.gs`。フィードバック用のスプレッドシートの「拡張機能」→「Apps Script」に貼り、`setup` を1回実行してから、ウェブアプリ（実行：自分、アクセス：全員）として公開する。届いたものは、写真をドライブのフォルダ「ピタBA フィードバック写真」（持ち主だけが見られる）に保存し、スプレッドシートの「アプリから」タブに1行（日時・お名前・改善要望・写真のリンク・アプリの情報）足して、持ち主にメールで知らせる。いたずら対策：アプリ以外からの送信と空の送信は受け付けない、1日100件まで、写真は1回3枚・1枚3MBまで、文は2000字まで、表の数式として動かないようにする
- 新しい版の確認：設定画面のいちばん上の大きなボタン「新しい版を確認」。結果はその場に出て、新しい版があればボタンが「新しい版に更新する」に変わる
- 保存した写真は、その端末の中だけ（インターネットには送らない）。ほかの人や、別の端末からは見えない
- **下のタブ（5つ）**：カメラ／ビフォー（ビフォーの置き場。選んで「アフターを撮る」でアフターを撮れる）／ビフォーアフター（ビフォーアフターの置き場。上の「＋ 写真から新しく作る」で撮らずに作ったものも、撮って作ったBAと同じ置き場に入る）／動画（Pro プランで提供予定。今は「準備中」の画面だけ）／設定。ビフォー・ビフォーアフター・動画・設定はタブで開く画面で、もう一度「カメラ」を押すと戻る。左上の「設定」ボタンと、シャッター左の下のタブ「撮らずに作る」はなくした
- 画面の並び（カメラ）：上の段は、左に「線の色」とその下に「ガイド（ビフォー画面では連続撮影）」、右に「自動撮影」（0.5x・1x の上）。シャッターの左は上から「写真から選ぶ」「撮り直し」の2段、右は0.5x・1x／比率・カメラ切り替えの2段（どれも同じ幅・同じ高さ。横持ちも縦持ちと同じ並び）。向きを変えたら操作欄を作り直す（iPhone で横→縦に戻したときに崩れないように）
- 設定画面（左上の「設定」）：ピタッの音・シャッター音・グリッド・手前（画面の下のほう）も合わせる・水平・垂直ガイドのON/OFF、ビフォーの自動撮影までの時間
- 撮影中はビフォーから壁・窓・家具の縁などの輪郭だけを取り出し、線にしてカメラ映像に重ねる（線は長い辺1280画素の大きさで作り、くっきり細く見せる。輪郭はすべて重ねる。そのうち壁・床・天井の境目、窓枠、家具の縁などの長くまっすぐな線（「ピタッ」の判定に使う線）は選んだ色、服や小物などそれ以外の輪郭は白で出す。一致度の計算は小さい画像のまま）（線の色は 赤／青／緑、「線なし」で重ねない。濃さも調整可）
- 撮ったあとの自動補正（初期設定で ON）：現場では、だいたい合わせて撮れば十分にする。アフターのわずかなずれ（位置・大きさ・傾き）を、撮ったあとに測って直し、ビフォーとそろえる。直したあとにできる端のすき間が出ないよう、2枚を同じだけ少し拡大して切り出す（2枚の構図は保ったまま）。完成画面・重なりチェック・保存する画像のすべてに、そろえた2枚を使う（元の写真はそのまま残る）。ずれが大きいとき（位置8%・大きさ12%・傾き3.5度・切り落とし25% を超えるとき）も、あきらめずに、その範囲で直せるところまで直す（札に「直しました（できるところまで）」と出る）
  - **何をしたかを見せる（ブラックボックスにしない）**：完成画面は、まず元の2枚ですぐ出す（待たされる感じをなくす）。そのあと測って、そろえた2枚にふわっと切り替える。完成画像のすぐ上のまん中に札を出す：「ずれを測っています…」→「✓ 自動補正 ON　位置 2.7%・大きさ 0.3%・傾き 0.8° 直しました」（緑）。札を押すと「自動補正 OFF」（灰色、補正前の写真）になり、もう一度押すと戻る。選んだ ON・OFF は次も同じ。直さなかったときは「✓ ずれはありません」か「自動補正なし（ずれが大きいため／手がかりが少ないため、そのままにしました）」。設定画面のチェックはなくし、操作は札1つにまとめた
  - 測り方：ガイドと同じ精密な位置合わせ（144×256 で、ビフォーの強い輪郭がアフターの同じ向きの輪郭に重なるかを数える）を、撮ったあとの1回だけ、広く細かく探す（大きさは±12%を1%刻み→0.25%刻み、傾きは±3度を0.5度刻み、そのあと小数点以下まで）。試験では、直したあとのずれは位置0.1%・傾き0.1度以内。1回0.2〜0.4秒ほど
  - 直さないとき：重なりが弱い（0.2未満）、直してもあまり良くならない（0.03未満。もともと合っているときを含む）、ずれが大きすぎる（位置8%・大きさ12%・傾き3.5度を超える）、切り落とす量が多すぎる（拡大1.25倍を超える）。別の場所の写真を選んだときなどに、無理に直さないため
  - 限界：手前と奥でずれ方が違う（立ち位置が違う）ときは、写真を動かすだけでは全部はそろわない（多く写っているほうに合わせる）
- 重なりチェック：完成画面の写真のすぐ下のスライダーのつまみを左へ滑らせると、ビフォーが右へ・アフターが左へ寄って重なり、ずれを確かめられる（指を離すと戻る）。ビフォーは線画になって、アフター写真の上に重なる
- 1枚ごとの比率は 16:9／4:3／1:1 から選べる（どれも縦長。撮った後の完成画面でも変更可）
- 「BEFORE / AFTER」の文字を入れるか選べる。完成画面の「文字のデザイン」で、書体と位置を選べる（選ぶとすぐ完成画像に反映）
  - 書体（5種類）：標準（太いゴシックの丸い札。ビフォーは黒地に白文字、アフターはその白黒反転。どちらも少し透ける）／明朝（白い明朝体に細い下線）／クラシック（Didot の斜体に白いカード）／モダン（字間の広い細めの文字に四角い札）／ポップ（「はちまるポップ」の細い手書き風の文字の楕円のステッカー。傾けない。ビフォーは青、アフターはオレンジ。文字は BEFORE・AFTER）
  - 位置（8か所）：左上・中央上・右上・左下・中央下・右下・枠の外・上・枠の外・下（枠の外は、写真の上か下に白い帯を足してそこに入れる。標準だけは、札が白地と同化しないよう帯を薄いグレーにする）
  - 背景の色（12個を2段で。色の名前は出さず、色の丸だけ）：おまかせ（クラシックは茶色、明朝はベージュ、標準の枠の外は薄いグレー、ほかは白）／白／薄グレー／濃グレー／黒／ベージュ／茶色（コルクボードくらい）／焦茶色／パステルブルー／パステルグリーン／パステルピンク／パステルパープル。2枚の写真のすき間と、写真の四周の縁（すき間と同じ太さ）と、枠の外の帯の色になる。濃い色（濃グレー・黒・焦茶色）のときは、文字や札を明るくして読めるようにする。作品に保存され、開くと戻る
  - 書体は iPhone に入っているもの（ヒラギノ明朝、Didot、Avenir Next など）を使うので、電波がなくても保存画像に入る。ポップだけは「はちまるポップ」（Google Fonts、SIL Open Font License。英大文字だけを切り出して index.html に埋め込み済み）を使う
- 「保存・共有」から写真アプリに保存

## 開発の進め方

使ってもらっている人がいるので、公開中の版と、試している版を分ける。

| ブランチ | 中身 | どこで見られるか |
|---|---|---|
| `main` | 公開中の版 | https://youngestday.github.io/pitaba/ （GitHub Pages。使ってもらっている人はここ） |
| `develop` | 試している版 | https://develop.pitaba.pages.dev/ （Cloudflare Pages。push すると自動で更新） |

- 新しい機能や直しは `develop` で作り、試す用の URL で確かめてから、`main` に入れて公開する。`main` に入れるのは、作者が「出してよい」と言ったときだけ
- 試す用の URL は別のサイトなので、保存した写真や設定は、公開中の版と混ざらない
- `main` には、`develop` の自動補正をいったん取り消した変更（2026.11.17-45）が入っている。`develop` を `main` に入れるときは、その取り消しをもう一度取り消す（自動補正を戻す）必要がある

## 使い方

1. iPhoneのSafariかChromeで上のURLを開き、カメラの使用を「許可」する
2. 左側でビフォーを撮る（または「ビフォーを写真から選ぶ」）
3. 右側のカメラで、重なったビフォーに合わせてアフターを撮る
4. 完成画面で「文字を入れる」を選び、「保存・共有」で保存する

ホーム画面に追加すると、アプリのように起動できます（アイコンは `icons/`、Android 用の設定は `manifest.webmanifest`）。

## 作成

片付けデザイン
- **保存の知らせと操作の置き場（2026.11.20-50）**：ビフォーを撮ると「ビフォーに保存しました」（連続撮影のときは「（◯枚目）」付き）、アフターを撮ると「ビフォーアフターに保存しました」と出す。ビフォー画面の連続撮影ボタンは「Before連続撮影 OFF／ON」。「ビフォーアフター」タブの「＋ 写真から新しく作る」は、親指で押しやすいように下のタブのすぐ上に置く。設定の「新しい版を確認」は、フィードバックのすぐ上。完成画面の「最初から」は、丸いホームのアイコン（文字なし）。文字のデザインを開いているあいだは、自動補正の札を隠す
- **更新履歴（2026.11.20-53）**：設定の「今の版」のすぐ下の「更新履歴（何が変わったか）」を押すと開く。中身は CHANGELOG.md と同じ（index.html の `#changelog` に書いてある）
- **自動補正の不具合の直し（2026.11.24-68）**：ビフォーとアフターの画素数がちがう（0.5x と 1x で撮ったなど）と、そろえるときにビフォーを元の大きさのまま描いていたため、ビフォーが拡大されて左上にずれていた。アフターの大きさに合わせて描くようにした
- **戻る・補正の置き場（2026.11.28-75）**
  - 「ビフォーアフター」の一覧 → 修正画面 → 文字のデザイン と進んだら、「戻る」で1つずつ戻る。修正画面の「戻る」は一覧へ（修正画面ではホームのボタンを出さない）、文字のデザインと補正の画面の「戻る」（一覧から開いたとき。撮った直後は「完了」。補正は選んだものを使って戻る）は修正画面へ。「戻る」は「‹」の印だけのボタンで、強調しない（-77）。左上の「‹ 一覧」はなくした
  - 補正は作品ごと：新しく作るときは「補正なし」から始め、選んだ補正（なし／自動／手で合わせた）は作品に保存して、開くと戻る（-77。-75・-76 は全体の設定として覚えていたので、一度「自動」にすると次からも自動になっていた）
  - 画面の移り変わり（-79）：画面全体を横に押し出す（View Transitions）。進むとき（一覧→修正画面、修正画面→文字のデザイン・補正）は、今の画面が左へ出て次の画面が右から入る。「‹」で戻るときは、今の画面が右へ押し出され、前の画面が左から入る（0.32秒）。下のタブは動かさない。使えないブラウザと、動きを減らす設定のときは、すぐ切り替える。自動補正で合わせられなかったときも、案内はただ「補正なし」
  - 補正は、完成画面の下のボタンの「補正」から（手で合わせる画面。補正なし／自動／完了）。何を直したかの案内は、重なりチェックの下に文字で出す（押せない）
- **文字のデザインをタブで（2026.11.28-74）**：書体・位置・背景の色を、下のタブ（書体｜位置｜背景）で切り替えて1段ずつ出す（書体と背景は横に動かせる。位置は4つずつ2段）。完了（と、一覧から開いたときの戻る）はタブの右。完成画面・文字のデザイン・手で合わせるの3つで下の操作欄の高さを同じにして、写真の大きさを変えない。文字を入れないときは、書体の先頭の「なし」を選ぶ（-73 の「文字を入れない」のチェックは、これに置き換えた）。一覧のタップが iPhone で取り消されたとき（指がわずかに動いて pointercancel になったとき）も、離した位置がほとんど動いていなければタップとして扱う。開くあいだは「開いています…」と出す
- **修正画面と親指の位置（2026.11.28-73）**
  - 「ビフォーアフター」の一覧は、写真をタップするとすぐ修正画面が開く（1タップ）。選ぶのは右上の○（押せる範囲は広め）か、横になぞる。選んでいるあいだのタップは、選ぶ・外す
  - 自動補正の札は、写真の上から下（重なりチェックの上）に移した（親指で押しやすく、写真に重ならない）
  - 修正画面（「ビフォーアフター」から開いたとき）には「アフター撮り直し」を出さない（カメラで撮った直後は出す）
  - 「文字を入れる」のチェックは完成画面からなくし、文字のデザインで選ぶ（-74 で書体の「なし」に）
  - iPhone の Safari で、2回目に「修正する」と「このビフォーアフターを読み込めませんでした」になる件：保存場所から読み出した写真（Blob）をそのまま書き戻すと壊れることがあるので、中身を写した新しい写真にしてから書き戻す（freshBlob）
- **手で合わせる（2026.11.25-72）**：完成画面の自動補正の札（「タップで手で合わせる ›」）を押すと開く。アフターの写真の上にビフォーの線を重ね、1本指で動かす、2本指で広げる・回す（大きさ 0.7〜1.4倍）。切り落とされる外側は暗く見せる（切り落としは 1.5倍まで。それを超える動きは止める）。端の空きは作り物で埋めず、2枚を同じだけ切り出す。下の「補正なし」「自動」で、補正前・自動補正に戻せる（見比べにも使う）。「完了」で完成画像に使い、札は「✓ 手で合わせました」になる。手で合わせた分は作品に保存し（hand）、「修正する」で開いても残る（比率を変えると自動補正に戻る）。札を押したときの「補正前・補正後の切り替え」は、この画面の「補正なし」「自動」に置き換えた
- **上下の向きはビフォー基準（2026.11.25-71）**：「上に向ける／下に向ける」とスマホ形の枠は、0度（まっすぐ）を基準にせず、ビフォーを撮ったときの向きとの差だけで出す（現場では下に向けて撮ることも多いため）。比べるビフォーがないとき（ビフォーの画面、写真から選んだビフォー）は上下の案内を出さず、水平線だけ出す。真下・真上を向いて左右の傾きが測れないときも、上下の差は出す
- **一覧に戻る・操作の置き場（2026.11.24-70）**：「ビフォー」の「アフターを撮る」、「ビフォーアフター」の「修正する」「＋ 写真から新しく作る」で開いた画面では、左上に「‹ 一覧」を出し、押すと元の一覧に戻る（最初からやり直すと消える）。一覧で選んだときの操作（アフターを撮る／修正する・保存・削除・選択解除）は、親指で押しやすいよう、下のタブのすぐ上に出す（ビフォーアフターでは「＋ 写真から新しく作る」と入れ替わる）。一覧から開く前に、今の写真の作業用の画像を片付けて iPhone のメモリをあける。読み込めなかったときは、理由を（ ）に入れて出す
- **「ビフォーアフター」タブから開いた完成画面（2026.11.24-69）**：「修正する」「＋ 写真から新しく作る」で開いた完成画面では、下のタブは「ビフォーアフター」のまま光る。もう一度「ビフォーアフター」を押すか、文字のデザインの「戻る」（「完了」の左。このときだけ出る）で一覧に戻る。「カメラ」を押すとカメラ（新しいビフォー）へ。「修正する」で開いたときは、左右の写真をタップしての差し替えはしない（文字・比率などを直すだけ）。直したところは自動で保存される
